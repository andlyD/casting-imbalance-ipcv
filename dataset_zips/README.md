# Dataset zips

`def_front.zip` (781 defective images) and `ok_front.zip` (519 OK images) hold the
1,300 original 512 × 512 photographs, unchanged, so the online dashboard can use the
full test set. `app.py` unpacks them into `data/casting_512x512/` when it starts.

Source: Dabhi, R. (2020). *Casting product image data for quality inspection* [dataset].
Kaggle. https://www.kaggle.com/datasets/ravirajsinh45/real-life-industrial-dataset-of-casting-product
